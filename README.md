# PuuPark – Smart Parking Companion

A location-based mobile application developed using MIT App Inventor as a project exploring smart parking solutions.

## Overview

PuuPark is a mobile application prototype designed to help users interact with parking locations through an interactive map interface.

The application explores how location-based services and cloud-connected features can support a more convenient parking experience.

## Features

- Interactive map interface
- Location sensor integration
- Parking location markers
- Save and delete parking locations
- Navigation functionality
- CloudDB integration

## Technologies Used

- MIT App Inventor
- Google Maps / Map component
- Location Sensor
- CloudDB
- Visual programming with blocks
